# Job Radar

System that finds hiring managers and fresh job posts every day and prepares a first message for each.

## What it does

- Collects vacancies from Telegram channels and job boards.
- Removes duplicates and scores relevance with an LLM.
- Finds the person who makes the hiring decision and a way to contact them.
- Sends a short daily digest with a ready first message.

## Stack

Python, SQLite, LLM API, Telegram API, Airtable, Linux server with scheduled runs, pytest.
